# 团队环境同步（Team Environment Sync）

> 让一个团队共享同一套开发环境：工具、镜像源、环境变量、PATH、配置文件。
> 团队维护一个 GitHub 仓库，成员 fork/配置一次，之后 **oneinit 每次运行时自动检测并同步**。

## 架构

```
用户机器                              团队仓库（oneinit-team-env，可 fork）
┌─────────────────┐   ── fetch ──>   ┌──────────────────────────┐
│ ~/.oneinit/     │   <─ .sig 可选 ─  │ team.yaml（环境定义）     │
│  team.json      │                   │ team.yaml.sig（Ed25519） │
│  url / key/hash │                   │ scripts/sign.js          │
└─────────────────┘                   │ .github/workflows/sign.yml│
   │ 每次运行                          └──────────────────────────┘
   ▼
 maybe_team_sync（main.rs 启动钩子）
 1. 未配置 → 跳过；24h 内且内容哈希未变 → 跳过（零开销）
 2. 变化/首次 → 拉取 + 验签 → 逐个确认安装缺失工具 → 应用镜像/env_vars/PATH/config_files
```

## 快速开始

```bash
# 1. 团队 fork https://github.com/oneinitAI/oneinit-team-env 模板
# 2. 编辑 team.yaml（见下文格式），push 到 main
# 3. 每个成员执行一次：
oneinit team add https://raw.githubusercontent.com/<org>/<repo>/main

# 4. 之后每次运行 oneinit 自动检测同步；手动立即同步：
oneinit team sync --force
```

## team.yaml 格式

```yaml
team:
  name: "WebTeam"               # 团队名（status 显示）
  description: "Web 团队共享开发环境"
  version: "1"                  # 环境定义版本
  signing_key: "d8ee1d1c..."    # 可选：Ed25519 公钥 hex（配 team.yaml.sig）

envs:                           # 工具（3 层解析：内置/本地社区/远程注册表）
  node: "20"                    # → recipe 名 node20
  python: "3.11"                # → recipe 名 python3.11

mirrors:                        # 镜像源（写入用户级配置，幂等）
  pip: "tsinghua"               # 别名：tsinghua/aliyun/ustc，或完整 URL
  npm: "npmmirror"              # 别名：npmmirror/taobao，或完整 URL
  # yarn: "npmmirror"

env_vars:                       # 环境变量（Unix 写 shell profile；Windows 用 setx）
  NODE_ENV: "development"
  TEAM_NPM_REGISTRY: "https://registry.npmmirror.com"

path:                           # 追加 PATH（支持模板变量）
  - "{{user_home}}/myteam/bin"

config_files:                   # 配置文件模板（写入前预览 + y/N 确认）
  - path: "{{user_home}}/.npmrc"
    template: |
      registry={{mirror_npm}}

post_install:                   # 安装后命令（安全：默认拒绝，CLI 需 --allow-exec）
  - "echo 'Welcome to myteam!'"
```

模板变量（config_files / path 中可用）：
`{{user_home}}` `{{install_dir}}` `{{mirror_pip}}` `{{mirror_pip_host}}` `{{mirror_npm}}`

## 命令参考

| 命令 | 说明 |
|------|------|
| `oneinit team add <url> [--branch main] [--force] [--allow-exec]` | 配置团队环境：拉取 team.yaml + 验签 + 固定公钥（TOFU），随后立即同步。`--force` 覆盖旧配置/重新固定公钥 |
| `oneinit team sync [--force] [--allow-exec] [--dry-run]` | 立即同步。`--force` 忽略 24h 间隔与缓存哈希；`--dry-run` 只预览 |
| `oneinit team status` | 显示 URL / 团队名 / 签名状态 / 上次检查与同步时间 |
| `oneinit team remove` | 移除团队环境配置 |

URL 支持：`https://github.com/<org>/<repo>`、`https://github.com/<org>/<repo>.git`、
`https://github.com/<org>/<repo>/tree/<branch>`、`https://raw.githubusercontent.com/<org>/<repo>/<branch>`。

## 自动检测机制

- **频率**：每次运行 oneinit 时检查一次；距上次检查 <24h 则跳过（仅读本地配置，零网络）。
- **变化判定**：拉取 `team.yaml`（+`.sig`），SHA256 与本地缓存比对；未变则仅更新时间戳。
- **同步**：内容变化或 `--force` 时，逐个安装缺失工具（每个都显示安全横幅 + `y` 确认），
  然后应用镜像、环境变量、PATH、配置文件、post_install。
- **失败不阻塞**：检测/拉取失败仅输出 `[WARN]`，不影响主命令。
- **部分失败**：工具未全部安装成功时**不记录**已同步哈希，下次可重试（或 `--force`）。

## 签名验证（可选但推荐）

- 团队在 `team.yaml` 声明 `signing_key`（Ed25519 公钥 hex），仓库根提供 `team.yaml.sig`。
- 成员 `team add` 时 oneinit 验签并**固定公钥**（Trust-On-First-Use）。
- 之后每次同步强制验签：公钥不一致 / 签名不匹配 / 声明了 key 却缺 `.sig` → **拒绝同步**。
- 未签名仓库可正常使用（显示 `[WARN]` 提示）。
- 签名流程（模板仓库已内置）：
  ```bash
  node scripts/sign.js --gen-key        # 生成 TEAM_SIGN_KEY(私钥seed) + signing_key(公钥)
  gh secret set TEAM_SIGN_KEY --repo <org>/<repo> --body <seed>   # 私钥只进 GitHub secret
  # 公钥写入 team.yaml 的 team.signing_key，push 后 Action 自动签名
  ```
- 团队更换密钥后，成员需 `oneinit team add <url> --force` 重新固定。

## 安全模型

| 风险 | 缓解 |
|------|------|
| 恶意/被篡改的 team.yaml | 可选 Ed25519 验签（固定公钥），不匹配拒绝 |
| 工具安装执行命令 | 复用 `--allow-exec` 默认拒绝；每个工具安装前安全横幅 + `y` 确认 |
| post_install 任意命令 | 默认跳过，仅 `--allow-exec` 时执行（自动同步永远不执行） |
| 配置文件写入任意路径 | 预览 + `y/N` 确认；路径必须为 home 下绝对路径且不含 `..` |
| PATH 越界条目 | 拒绝含 `..` 的条目；path_mgr 幂等去重 |
| 检测/同步失败影响主命令 | 失败静默 `[WARN]`，不阻塞 |

## 与 `oneinit sync` 的区别

| | `oneinit sync` | `oneinit team sync` |
|---|---|---|
| 配置来源 | 当前目录 `oneinit.yaml` | 远程团队仓库 `team.yaml` |
| 自动检测 | 无 | 每次运行自动（24h 间隔） |
| 签名 | 无 | 可选 Ed25519 验签 |
| 覆盖范围 | envs + mirrors(仅日志) + post_install | envs + 镜像(真实应用) + env_vars + PATH + config_files + post_install |
